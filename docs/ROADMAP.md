# Trophy Hunter Dashboard — Roadmap / Next Steps

A status snapshot + what to do next, so a fresh session or contributor can pick
up without prior chat context. See also `docs/superpowers/specs/` (design) and
`docs/superpowers/plans/` (Phase-1 plan).

## Done (branch `redesign/modern-rebuild`)

- **Backend** (`backend/`, FastAPI): the token owner's OWN profile comes from the
  **official PSN API** (PSNAWP + NPSSO token in the repo-root `.env`) — trophies,
  rarity, earned dates (ISO), and **real playtime**. 24h profile cache + a
  **per-title trophy cache** keyed by each game's `last_updated`, so rebuilds only
  re-fetch recently-played games. PSNProfiles uses headed `nodriver` Chrome as the
  secondary source, with current-layout parser fixtures and bounded waits.
  Endpoints: `GET /api/profile/{username}`
  (own id → PSN API, else scrape), `/api/profile/{username}/stream` (SSE),
  `/api/hltb`, `/api/psnine`, `/api/psnprofiles/guide`,
  `/api/psnprofiles/stats`, `/api/health`. 54 pytest tests, pristine.
- **Frontend** (`frontend/`, Vite + React + TS + Tailwind CSS v4 + HeroUI v3,
  "Trophy Gold" theme): top-nav pages Overview / Games / Timeline / Milestones /
  Data. HeroUI supplies accessible generic controls (buttons, inputs, filters,
  sorting, and loading indicators), while the dashboard keeps its custom game,
  trophy, and chart visuals. Real playtime tile + per-game playtime, per-game
  external links (PSNProfiles / PSNine / HLTB / Metacritic / Exophase), and HLTB
  completion times on game cards. PSNine titles are resolved from its own search
  results, preferring Simplified Chinese while retaining English-only canonical
  titles, cached, and opened with a non-empty `?title=站內名稱`.
- **Run:** `./run.ps1` (Windows) → backend `:8000` + frontend `:5173`. First-time
  setup in `README.md`. Full `dakinwu20` cache pre-warmed: 165 titles / 5,286
  trophies.

Guide cards now load PSNProfiles difficulty / platinum time on demand and
upgrade the search link to the exact guide URL after a successful lookup.

### 4. Trophy Advisor
- ~~Full private library advisor~~ — DONE. The token owner's active digital
  PS3/PS4/PS5 entitlements are loaded from Sony's PlayStation web library API and
  cached for 24 hours, including never-launched titles. The Advisor tab filters
  the library, preserves separate cross-gen editions, and enriches a manually
  selected batch of up to 50 games with PSNProfiles tracked-owner, average
  trophy-completion, and platinum statistics. The frontend can automatically
  continue through every filtered candidate as sequential safe batches. Advisor
  scores prioritize PSNProfiles platinum rate and log-scaled platinum achievers;
  general completion and tracked-owner totals remain reference-only. Optional
  backend-only Gemini 2.5 Flash resolution uses Google Search grounding to convert
  localized source titles to verified English PSNProfiles search terms and caches
  them for 180 days. Existing English names consume no Gemini quota; localized
  names use independently cached grounded batches of up to 12 games.
  Multi-list collections are expanded into independently scored child games;
  known mappings are local, while unknown collections use batched Google Search
  grounding on Gemini 2.5 Flash with the same key and a 180-day cache. Trial, Demo,
  Beta, playtest, test-version entitlements, and trophy sets where the owner has
  already earned platinum are excluded before enrichment. Endpoints:
  `GET /api/profile/{username}/advisor` and `POST /api/psnprofiles/advisor`.
  Physical discs and inactive entitlements may not appear in Sony's response.
