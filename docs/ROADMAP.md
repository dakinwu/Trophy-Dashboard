# Trophy Hunter Dashboard — Roadmap

這份文件描述目前功能與後續工作，不包含個人帳號、快取紀錄或私人開發筆記。安裝與行為細節以 [README](../README.md) 及實際程式碼為準。

## 目前功能

- FastAPI 後端與 React／TypeScript 前端，採 HeroUI v3、Tailwind CSS v4、Recharts 與 Trophy Gold 主題。
- Overview、Games、Trophy Advisor、Timeline、Milestones、Data 六個頁面。
- 自己的資料優先使用官方 PSN；其他玩家可先取得官方公開摘要，必要時使用 PSNProfiles 替代來源。
- Profile、收藏庫、遊戲明細、攻略、排名、名稱解析與圖片各自使用快取；有效期限見 README。
- 個別遊戲可查看取得時間、獎盃類型、DLC 標示，以及分開標示來源的 PSN／PSNProfiles 獲取率。
- 白金圖庫獨立取得官方白金清單；官方圖片驗證後保存本機，避免只依賴不完整的獎盃紀錄或外站直接載入。
- Advisor 讀取憑證擁有者的有效數位收藏庫，包含未啟動遊戲；並非完整 PS Plus 目錄。
- 推薦優先考量白金率與白金玩家數，支援權重調整、篩選與有上限的分批分析。
- 排除已白金、試玩／測試及可辨識的非遊戲內容；同作品跨世代授權可合併，已知 PS4→PS5 自動跳杯機會另行標示。
- 合集展開為子遊戲；名稱與未知合集可按需使用 Gemini 搜尋輔助解析，成功結果會快取。
- 查詢失敗保留經驗證的上次成功資料與原時間；已知驗證挑戰停止自動重試，不假裝取得新資料。
- 後端提供 SSE 載入進度、受限來源的圖片端點，以及具輪替機制的本機日誌。

## 已知限制

- 本機個人使用，沒有多使用者登入與權限隔離；**不應直接公開部署**，詳見 [SECURITY](../SECURITY.md)。
- 官方資料、數位授權及公開玩家摘要可能受憑證、隱私與授權有效性影響。
- PSNProfiles 可能出現人工驗證、外站改版或資料缺漏；自動測試不能保證每款遊戲即時可爬取。
- 名稱、合集與非遊戲內容的判斷不是完整官方商店分類，仍可能漏判。
- 自動跳杯使用內建來源與查核日期，不等於即時確認所有版本或地區的支援情況。
- 部分玩家只有公開摘要，不能據此捏造逐筆獎盃、取得時間或私人遊玩時數。

## 建議後續工作（尚未完成，不代表功能承諾）

- [ ] 建立自動化驗證流程，執行前端 lint／build 與後端測試，不使用真實帳號憑證。
- [ ] 補上前端資料轉換與互動的自動測試，尤其是推薦、快取狀態與重複請求防護。
- [ ] 擴充名稱／版本／合集／非遊戲內容的匿名化回歸範例，避免修正一款卻誤配另一款。
- [ ] 設計可檢視、更新與清除「單一項目」快取的管理流程，避免整庫重跑。
- [ ] 持續查核自動跳杯來源、日期與版本限制；未確認時保留未知。
- [ ] 以不含真實帳號資料的展示素材補充響應式與無障礙驗證。

未來若需要多人或公開服務，必須先另行設計身分驗證、授權隔離、憑證保管、流量限制與部署威脅模型；不屬於目前本機版本的保證。
